# پروپوزال طراحی هسته Component System

## هدف

طراحی یک سیستم Component عمومی که:

* قابل توسعه باشد.
* برای رسم شماتیک مناسب باشد.
* برای Undo/Redo آماده باشد.
* برای Save/Load آماده باشد.
* برای موتور شبیه‌سازی آماده باشد.
* برای Copy/Paste آماده باشد.
* برای SubCircuit آماده باشد.
* برای Library آماده باشد.
* برای پروژه‌ای در سطح Proteus کافی باشد.

---

```text
└── Library
```

# کلاس پایه Component

## ۱) اطلاعات شناسایی (Identity)

تمام Component ها باید داشته باشند.

```cpp
QUuid id;

QString name;

QString type;

QString category;
```

مثال

```
id = 52...

name = R1

type = Resistor

category = Passive
```

---

## ۲) اطلاعات گرافیکی

```cpp

qreal rotation;

bool mirrored;

qreal zValue;
```

توابع

```

shape()
```
